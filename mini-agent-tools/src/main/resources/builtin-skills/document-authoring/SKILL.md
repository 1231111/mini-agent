# Document authoring

Use this skill when the user asks for a report, proposal, presentation, spreadsheet, or other finished document.

1. Identify the audience, purpose, requested format, language, and any required sections. If a minor detail is missing, use a sensible default and state it briefly; ask only when the missing choice changes the deliverable materially.
2. Draft for the intended reader, not as a transcript of the prompt. Use a clear hierarchy, concise headings, consistent terminology, and concrete conclusions. Preserve supplied facts and label assumptions.
3. Use `write_document` for Word, PowerPoint, Excel, Markdown, HTML, or text output. Match the output extension to the requested format and save it in the workspace unless the user names another allowed location.
4. For spreadsheets, include descriptive headers, one record per row, and keep units and date formats consistent. For presentations, give each slide one main point and use short, readable text.
5. Report the exact output path and format. Do not claim that a file was visually inspected or compiled unless that verification actually happened.
